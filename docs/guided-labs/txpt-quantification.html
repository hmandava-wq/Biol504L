Today’s lab will include preparing data for transcript quantification with the pseudo-alignment tool, Salmon.

Preparing the Salmon index

Salmon is a pseudo-alignment tool, which quickly “aligns” your raw reads to a transcriptome. To do make this fast and accurate, Salmon needs the transcriptome formatted in a specific way to facilitate its work. This is called indexing and is a common step for many bioinformatic tools.

  1. To generate the indexed dataset for Salmon, we need to prepare a file with the transcriptome and genome together since we are using the genome as a “decoy” to improve the mRNA quantification. This is easily done with another wonderful terminal command, cat.

    cat can either show you everything inside a file or “concatenate” (merge) files together. Today we will merge the genome and transcriptome.

    TipHow cat works

    cat merges files together in the order that you provide them. This means that every subsequent file is “merged” to the bottom of the prior file(s).

    This is really important as Salmon expects the genome (our “decoy”) sequences to be at the bottom of the file. So you just put the transcriptome first followed by the genome and make sure to store the output, using > to a new file.

    The command is below to help illustrate this! While we are using just two files, this command will work for any number of files!

    cat Drosophila.Transcriptome.fasta Drosophila.Genome.fasta > Drosophila.Txm_Gnm.fasta

  2. You can now remove the Drosophila.Transcriptome.fasta and Drosophila.Genome.fasta files from the HPC.

    TipIn case you get stumped 
    rm some-file

  3. Now we can prepare to generate the Salmon index. First, load conda and activate the txpt_quant container.

    If you do not have the txpt_quant container, refer back to the access-setup-hpc guided lab on how to make new containers and install software.

  4. With your container active, you need to make another job submission script! Go ahead and copy the fastq_trim.sh script and save it as salmon_run.sh.

  5. Inside this script, you will need to remove the exising fastp command, then add the following commands to generate the index that Salmon needs for our Drosophila data.

    salmon index \
     -p 8 \
     -d decoys.txt \
     -i dmel_index \
     -t Drosophila.Txm_Gnm.fasta

    Here is a breakdown of the command:

    • index: tells Salmon that we are preparing its index
    • -p: number of threads to use (this should ideally be the same as --ntasks)
    • -d: PATH to the decoys.txt file (these are just the name of the genome sequences)
    • -i: what you would like Salmon to name your index
    • -t: PATH to the merge transcriptome and genome fasta files

  6. All you need to do now is submit the job submission script!

    TipIn case you get stumped 
    sbatch salmon_run.sh

Quantify Transcript Abundance!

With the index prepared, it is fairly easy to start quantifying transcript abundance from each of the trimmed reads, which were prepared before.

  1. First, let’s update the existing salmon_run.sh file. This time instead of deleting the command, let’s leave it there. However, add one # in front of each line in the command to “comment out” the command. This will prevent it from being run each time this script is submitted.

    This is a nice way to leave useful bits of code in these job submission scripts that we use rarely. It can serve as a nice reference for later!

  2. Now add the command to run the quantification to the salmon_run.sh script.

    salmon quant -i dmel_index \
   -l A \
   -1 forward.fastq.gz \
   -2 reverse.fastq.gz \
   -p 8
   -o Salmon_Quant/outname_Quant

    Here is a breakdown of the command:

    • quant: tells Salmon that we are quantifying transcript expression
    • -i: PATH to the Salmon index
    • -l: specify what type of sequencing library we used (A tells Salmon to determine this automatically)
    • -1: PATH to the forward reads
    • -2: PATH to the reverse reads
    • -p: number of threads to use (this should ideally be the same as --ntasks)
    • -o: what you would like Salmon to name the output directories it is going to make

    There are some placeholder names that you can update!

Caution

The steps below are to show you how to run the transcript quantification with just one set of trimmed reads.

You will need to update the names as appropriate.

This can be automated a bit more, but I want to stress that being pushed to touch and update these files repeatedly will help it become more familiar and easy to do!

  1. For each of the sets of reads, it would be best to provide the full path to the trimmed reads in the script. Especially, as you should be working in your transcript_quantification folder, we do not have to any confusing navigation.

    In the code below are the PATHs to my files. You should update it accordingly!

    salmon quant \
     -i dmel_index \
     -l A \
     -1 /sciclone/scr10/xxmaureralcala/Biol404L/raw_read_prep/Dmel_Maine_21C_Rep1.Fwd.20q.80nt.fastq.gz \
     -2 /sciclone/scr10/xxmaureralcala/Biol404L/raw_read_prep/Dmel_Maine_21C_Rep1.Rev.20q.80nt.fastq.gz \
     -p 8 \
     -o Salmon_Quant/Dmel_Maine_21C_Rep1_Quant

    You can see that I added the sample information to the -o to make it clear which set of trimmed reads were being processed.

  2. Submit the salmon_run.sh script and feel free to update it with new sets of reads and repeat!

  3. Sit back and rest for a moment! We are finally about to touch some results! Yay!
